# Челлендж 100 дней — автономная версия

Приложение для отслеживания 100-дневного тренировочного челленджа.
Вытащено из артефакта Claude и отвязано от платформы: теперь работает
где угодно, данные хранятся в браузере (localStorage).

**Открыть:** https://ssb000ss.github.io/challenge-100/

## Файлы

- `index.html` — само приложение (весь UI + логика, один файл)
- `data.json` — программа на 100 дней и библиотека из 163 движений (только чтение)
- `tools/build_program.py` — генератор программы, `tools/validate_program.py` — проверка
- `README.md` — этот файл

## Как запустить

Приложение грузит `data.json` через `fetch`, поэтому **просто открыть
index.html двойным кликом не выйдет** — браузер заблокирует fetch с file://.
Нужен локальный сервер. Любой из вариантов:

```bash
# Python (есть почти везде)
cd challenge-100
python3 -m http.server 8000
# открыть http://localhost:8000

# или Node
npx serve
```

Для телефона: подними сервер на компе, зайди с телефона по IP компа
(`http://192.168.x.x:8000`), пока оба в одной сети. Либо задеплой статику
куда угодно. Боевая версия живёт на GitHub Pages и обновляется
при каждом пуше в `main`.

## Как устроены данные

**Не меняется (data.json):**
- `days` — 100 дней. У каждого: `title`, `payload` (основная тренировка),
  `variant` (облегчённый вариант на замену). Внутри payload — `blocks`,
  в каждом блоке `items` с полями `movement` (код), `text` (подходы×повторы,
  вес), `note`.
- `moves` — 163 движения по коду. Поля: `name_ru`, `cue` (техника),
  `equipment`, `category`, `unlock_day`, `media_url`.

**Меняется, лежит в localStorage под ключом `challenge100`:**
- `state` — `started_on`, `swaps_left` (замены, старт 3), `dayoff_left`
  (отгулы, старт 1), `bench_max`, `status`.
- `logs` — по дням: `outcome` (`done`/`swap`/`dayoff`/`open`),
  `items` (индексы отмеченных пунктов), `note`, `swapped` (взята замена,
  день ещё открыт).

## Логика (важно)

- **Текущий день = по календарю:** день 1 — дата старта (`state.started_on`),
  сегодня 22.09 → день 2.
- Отмечать можно только сегодняшний день. Закрыл сегодня — можно посмотреть
  завтрашнюю тренировку, но без галочек. Дальше завтра и назад — нельзя.
- Прошедший незакрытый день — **пропуск**: красный в полоске и в «Истории»,
  серия с нуля, челлендж продолжается. Пропуск вычисляется, в `logs` не пишется.
- Закрытые дни из `data.json.logs` — факты (например, засчитанный день 1):
  они применяются, если в браузере этот день не закрыт.
- «Поменять» списывает замену и показывает облегчённый вариант; его тоже нужно
  отметить и закрыть — тогда день засчитан как `swap`.

## Что стоит доделать (backlog)

1. **Пуш-напоминание в 7 утра.** Сейчас нет. Варианты: PWA + Notification
   API (сработает только когда вкладка живёт), или отдельный телеграм-бот
   рядом, который читает тот же data.json и пингует по расписанию.
2. **Медиа к движениям.** Сейчас `media_url` — это ссылка на поиск в
   YouTube, не на конкретное видео. Заменить на прямые ссылки или свои ролики.
3. **Пересчёт по контрольным дням.** Веса блоков 2–4 зависят от
   результата дней 28/56/84 — сейчас правило только в тексте дня.
4. **Замеры и прогресс-графики.** Вкладка «Прогресс» есть, но данные
   замеров (вес, талия, обхваты) пока никуда не пишутся — добавить форму.

## Как пересобрать data.json

Программа генерируется скриптом — правь таблицы в его начале и запускай:

```bash
python3 tools/build_program.py      # перезаписывает days и moves в data.json
python3 tools/validate_program.py   # веса по железу, запрещённые движения, защита плеча
```

`state` и `logs` генератор не трогает. Прогресс пользователя живёт в браузере.

## Экспорт и импорт

Вкладка «Прогресс» → «Данные». «Выгрузить» сохраняет `challenge100-ГГГГ-ММ-ДД.json`
(на iPhone — через меню «Поделиться» → «Сохранить в Файлы»). «Загрузить» проверяет
файл и после подтверждения заменяет прогресс в этом браузере.

## Фото и техника упражнений

Тап по упражнению раскрывает фото (начало и конец движения), пошаговую технику
на русском и ссылку на видео.

- Сопоставление упражнение → фото: `tools/exercise_images.json`, файлы в `media/ex/`.
- Шаги техники: `tools/exercise_steps_ru.json` — переведены и адаптированы
  под ограничения (колено, спина, плечо).
- Фото: [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
  (Unlicense, public domain) и [wger.de](https://wger.de) (CC BY-SA 4.0:
  Bird Dog — Settebello; Knee Raises, Kettlebell deadlifts — участники wger).
- Где точного фото нет (плавание, ходьба, часть растяжек, переноски одной
  рукой, сплит-присед на месте), показываются только шаги — неверная картинка
  хуже, чем никакой.

## Офлайн и установка на телефон (PWA)

- `manifest.webmanifest` + `icons/` — установка на экран «Домой» как приложение.
- `sw.js` — service worker: при первом открытии кэширует страницу, `data.json`
  и все фото упражнений (~6 МБ). Страница и программа — «сначала сеть» с таймаутом
  3 секунды, затем кэш; фото, иконки и шрифты — «сначала кэш».
- Правки `index.html` и `data.json` доезжают сами при следующем открытии с сетью.
  `VERSION` в `sw.js` поднимать, только если меняется список файлов оболочки.
- iPhone: Safari → «Поделиться» → «На экран Домой». У приложения с экрана «Домой»
  своё хранилище, отдельное от Safari: прогресс переносится через экспорт/импорт.
